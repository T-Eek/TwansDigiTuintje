Welkom op mijn Digitale Tuin!

Om deze website goed te laten werken en transparant te zijn over jouw privacy, informeren we je graag over hoe deze site is opgebouwd en welke gegevens worden verwerkt van de site.

Welke externe diensten en onderdelen worden er gebruik?

  • GitHub Pages/ TransIp: TransIP Wordt gebruikt voor de hosting van de domein naam en Github Pages wordt gebruikt voor de repository en de website.

  • Digitaaltuintje Webring Component: Verbindt deze tuin met het netwerk van de digitale tuintjes via een webring-component.

  • Google Fonts: Wordt gebruikt voor de typografie, op deze website, de eigenaar heeft geen eigen font ontworpen, maar maakt gebruik van gedownloaden google fonts.

  • Thrid party links: Wordt gebruikt om de CSS Deep Dives, structuur en vorm te geven doormiddel van een Codepen template link van de eigenaar van de Codepen.

Voor de rest is alles op deze website volledig door mijzelf ontworpen en geprogrammeerd! Er worden geen onnodige tracking- of advertentiecookies geplaatst.
